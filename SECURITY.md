# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through
[GitHub Security Advisories](https://github.com/Emil-02/QiblaHub/security/advisories/new)
and include steps to reproduce. You will get a response within 7 days, and a fix
or mitigation will be released as soon as possible. Thank you for helping keep
QiblaHub and its users safe.
